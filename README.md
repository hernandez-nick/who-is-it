# Who Is It?

![who is it game](https://i.ibb.co/vxg2SJr8/Screenshot-2026-01-20-at-5-50-02-PM.png)

## Description

**"Who Is It?"** is a single player trivia game. The player guesses the name of a famous person shown in an image. Categories include athletes, musicians, and actors or actresses. There are a total of 20 questions per category worth 1 point each. If the player gets 7 questions wrong, the game ends. If the player reaches level 20, the game ends and the player can choose to play again or choose a different category.


## Pseudocode
Game Setup: 
* Create three categories.
* Each category will have 20 images and answers.
* Set score to 0.
* Set level to 1.
* Load sounds for start, correct and wrong answers.*

Start Game:
* Show the title.
* Show the category buttons.
* When a category is selected,
* Start the game.
* Reset score and level.

Play Game:
* Show one image.
* Show input box and submit button.
* Show score and level number.
* Player types a guess.
* Player submits a guess.

Check Answer:
* If the guess matches the correct answer,
* Increase score by 1.
* Play correct sound.
* If the guess is wrong,
* Play wrong sound.
* Show the correct answer.
* Move to the next level.

End Game:
* If all 20 levels are completed,
* Show final score.
* Show play again option.
* Show category selection option.

Restart:
* If player chooses play again,
* Reset score and level.
* Start the category again.
* If player chooses category,
* Return to the start screen.
